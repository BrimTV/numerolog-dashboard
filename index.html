Кто сколько привёл по реф-ссылкам из отзывов — и как далеко дошли приведённые. Метка у человека одна: первая, с которой он перешёл — поэтому строки не пересекаются, каждый считается ровно один раз. Кто пришёл вообще без ссылки, идёт в строку Николая. «Подписалось» — по журналу переходов (ведётся с 30.07), «в воронке» — по всем дошедшим до бота, поэтому там второе число может быть больше первого. Строки «↳ вся ветка» ВЛОЖЕНЫ друг в друга и не складываются: ветка Гончаровой целиком лежит внутри ветки того, кто привёл её саму. Сходится только первая строка каждого — по ней сумма всех меток даёт ровно итог блока «Донаты».
